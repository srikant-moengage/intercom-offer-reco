Hello World Intercom Messenger App
=================

[**Follow the steps here in order to get your app up and running.**](https://developers.intercom.com/docs/build-an-integration/getting-started/build-an-app-for-your-messenger/)

Once this is done, you can see the webview to find the URLs which need to be added to your app in the Intercom developer hub.

After you finish set up you will have a simple app which lets you submit a CSAT/feedback form from your Messenger home screen. You can use this as a starting point to add in more functionality utilizing Canvas Kit to build any integration within the Intercom Inbox and Messenger.

---

In Your Project
------------

`index.html`:
- Basic styling
- The endpoint URLs that will display

`index.js`:
- The Express server
- The Canvas Kit webhook endpoints

Required packages for this quickstart are in `package.json`
